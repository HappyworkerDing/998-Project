## 组件详细说明

### 1. Header (顶部导航栏)
- **位置**: 固定在页面顶部 (sticky)
- **内容**: 
  - 返回按钮
  - 模块标题 + 图标
  - 模块标识徽章

### 2. Overview Card (概览卡片)
- **布局**: 3列网格
- **卡片内容**:
  - 算法名称 (AE-WoLF-BSS-Q)
  - 负责人 (Yanqing Lv)
  - 训练阶段 (Pretrain/Independent/Joint)

### 3. Training Control (训练控制)
- **按钮组**:
  - ▶ Start Training (开始训练)
  - ⏸ Pause (暂停)
  - ↻ Reset (重置)
- **状态显示**:
  - Episode 计数
  - 训练状态指示器 (动画脉冲)

### 4. Core Metrics (核心指标 - 4个卡片)
- **Q-Learning 卡片** (蓝色主题)
  - 平均 Q 值 (大号数字)
  - 学习率
  - 探索率 (ε)
  - WoLF 模式标识 (WIN/LOSE)
  
- **WoLF Status 卡片** (蓝色主题)
  - 策略价值
  - 平均策略价值
  - 连胜次数
  
- **BSS Game 卡片** (紫色主题)
  - 主导攻击者类型
  - 类型信念分布 (APT/DDoS/Ransomware/Mixed)
  
- **Attention 卡片** (橙色主题)
  - 注意力准确率@10 (百分比)
  - Top-K 节点数
  - 进度条可视化

### 5. Training Progress Chart (训练曲线图)
- **图表类型**: 多线折线图
- **数据系列**:
  - 累积奖励 (Reward) - 绿色
  - 平均 Q 值 (Q-Value) - 蓝色
  - 注意力准确率 (Attention) - 橙色
- **X轴**: Episode 数量
- **Y轴**: 指标数值
- **特性**: 实时更新，保留最近50个数据点

### 6. Network Topology (网络拓扑可视化)
- **布局**: 5x3 网格
- **节点显示**:
  - 节点ID (数字)
  - 颜色编码 (根据注意力权重)
    - 高注意力: 主色高亮 + 放大
    - 中等: 橙色
    - 低: 灰色
  - 透明度 (根据注意力权重)
- **排序**: 按注意力权重降序
- **显示数量**: Top 15 节点

### 7. Recent Decisions (最近决策日志)
- **布局**: 垂直列表
- **每条记录包含**:
  - Episode 编号
  - 动作描述 (如 "Firewall Update - Node 5")
  - 奖励值 (带颜色徽章)
  - 时间戳
- **显示数量**: 最近 5 条

### 8. Technical Details (技术详情标签页)
- **标签**: Framework / Algorithm / Scenarios
- **内容**: 算法说明、框架介绍、场景描述

## 颜色方案

- **主色调**: Primary (蓝色系)
- **Q-Learning**: Primary blue
- **WoLF**: Blue-500
- **BSS**: Purple-500
- **Attention**: Orange-500
- **背景**: Gradient from background to muted/30
- **卡片**: Border-border/50, bg-muted/30

## 响应式设计

- **移动端** (< 768px): 单列布局
- **平板** (768px - 1024px): 2列布局
- **桌面** (> 1024px): 4列指标卡片，2列内容区域

## 交互特性

1. **实时更新**: 训练过程中指标每秒更新
2. **动画效果**: 
   - 进度条过渡动画
   - 训练状态脉冲动画
   - 图表平滑更新
3. **状态管理**: 
   - 训练/暂停状态切换
   - Episode 计数递增
   - 数据历史保留

## 数据流

```
用户点击 Start Training
    ↓
setInterval 启动 (每秒执行)
    ↓
更新所有指标 (随机生成模拟数据)
    ↓
更新训练曲线数据点
    ↓
更新节点注意力权重
    ↓
每5个episode添加决策日志
    ↓
UI 自动重新渲染
```
